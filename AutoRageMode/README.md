# Auto Rage Mode 1.2.1

Enhanced copy of Auto Rage Mode with Mega Horde support.

Press the configured Rage toggle key (`T` by default) to cycle through the original modes:

1. Off
2. Souls Horde Only
3. Horde Only
4. Auto Rage

Two independent settings can be enabled on top of any original mode, including Auto Rage or Off:

- `ResetRageAndActivate`: when a Mega Horde starts, reset the Rage Mode cooldown and activate Rage.
- `ResetRageActivateWithItems`: do the same and also activate **Shards Necklace** and **Souls Compass**.

If both settings are enabled, the second setting takes effect without activating Rage twice. An item is not crafted again while it is already active. If an item is unavailable or its requirements/materials are missing, the mod logs a warning and still activates Rage Mode.
